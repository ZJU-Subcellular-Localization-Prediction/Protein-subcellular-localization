# 蛋白质亚细胞定位预测 — 小组分工计划书

> 基于开源项目 [Protein-subcellular-localization](https://github.com/ClaudiaRaffaelli/Protein-subcellular-localization)（TensorFlow/Keras 实现），进行技术栈现代化重构。
>
> **交付日期**：2026 年 5 月 28 日 | **剩余天数**：8 天

---

## 项目背景与目标

原项目使用 TensorFlow/Keras 实现了基于深度学习的蛋白质亚细胞定位预测，包含 7 种对比网络架构（FFN → CNN → BLSTM → CNN+BLSTM → BLSTM+Attention → CNN+BLSTM+Attention → 完整版）。

我们的目标：
- **抛弃**旧的 PSI-BLAST/PSSM 和 ELMo 特征提取管线，改用 HuggingFace **ESM-2** 蛋白质语言模型提取特征
- 用 **PyTorch** 重写核心模型架构（CNN + BLSTM + Attention）
- 新增 **Java 后端** + **Vue 3 / Element Plus 前端** + **MySQL**，构建完整 Web 应用
- 包装成可用于期末答辩的系统演示

## 模块二：团队分工建议

### CS 同学职责（技术核心）

#### 任务 1：ESM-2 特征提取脚本（预计 1.5 天）

- 使用 `transformers` 库加载 `facebook/esm2_t30_150M_UR50D`（推荐）或 `esm2_t12_35M_UR50D`（CPU 环境）
- 解析 `DeepLoc.rtf`，提取蛋白质序列和标签（复用 `datasetOnehot.py` 的解析逻辑）
- 对每条序列进行 ESM-2 推理，提取 per-residue 特征向量
- 实现序列中心截断/末端 padding 到固定长度（推荐 1000），保护 N/C 端信号
- 将特征保存为 `.pt` 格式供 PyTorch 模型加载
- 同时保存标签（10 类亚细胞定位 + 3 类膜结合状态）

**关键参考文件**：`utils/datasetOnehot.py`

#### 任务 2：PyTorch 模型重构（预计 2 天）

参考 `utils/models.py` 的 7 种架构，用 PyTorch 重写：

| 序号 | 架构 | 说明 |
|------|------|------|
| 1 | `Attention` 层 | Bahdanau additive attention（nn.Module 实现） |
| 2 | `FFN` | Feed-Forward Network（baseline） |
| 3 | `CNN` | 双分支 Conv1d(kernel=3,5) → Concat → Conv → MaxPool |
| 4 | `BLSTM` | 双向 LSTM（forward + backward，取最后 hidden state） |
| 5 | `CNN+BLSTM` | CNN 特征提取 + 双向 LSTM |
| 6 | `BLSTM+Attention` | 双向 LSTM（return_sequences=True）+ Bahdanau Attention |
| 7 | `CNN+BLSTM+Attention` | CNN + BiLSTM + Attention（最佳对比模型） |
| 8 | `CNN+BLSTM+Attention_complete` | **最终模型**：6 并行 Conv1d(kernel=1,3,5,9,15,21) → Concat → Conv(kernel=3, 128 filters) → BiLSTM → Attention → Dense → Softmax |

**评估指标复现**：
- Gorodkin（多类 MCC，使用 `sklearn.metrics.matthews_corrcoef`）
- MCC（膜结合状态二分类/三分类）
- 混淆矩阵（10×10 亚细胞定位 + 3×3 膜结合状态）
- Attention 权重可视化

**训练脚本要求**：
- 支持 train/val/test 流程
- 保存最佳模型权重（`.pt`）
- 记录 loss/accuracy 曲线
- 输入维度兼容 ESM-2（640 维 per-residue）或 one-hot baseline（20 维）

**关键参考文件**：`utils/models.py`、`trainings/rs_cnn_lstm_attention_complete.py`

#### 任务 3：Java 后端 + MySQL（预计 2 天）

**API 设计**：

**MySQL 表设计**：

```sql
CREATE TABLE sequences (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    sequence_id VARCHAR(64) UNIQUE NOT NULL,
    raw_sequence TEXT NOT NULL,
    sequence_length INT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE predictions (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    sequence_id VARCHAR(64) NOT NULL,
    predicted_location VARCHAR(64) NOT NULL,
    location_confidence DOUBLE NOT NULL,
    predicted_membrane VARCHAR(32),
    membrane_confidence DOUBLE,
    all_probabilities JSON,
    attention_data JSON,
    model_version VARCHAR(32),
    inference_time_ms INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (sequence_id) REFERENCES sequences(sequence_id)
);
```

**Python 调用方式**：Java 通过 `ProcessBuilder` 调用 Python 推理脚本，传递序列参数，解析 stdout JSON 返回结果。使用 JDBC 或 MyBatis-Plus 操作数据库。

#### 任务 2：分层树（Hierarchical Tree）生物学意义解析（预计 1 天）

- 研究细胞内蛋白质分选途径：
  - **分泌途径**：核糖体 → 内质网 → 高尔基体 → 细胞膜/胞外/溶酶体
  - **核定位途径**：细胞质 → 核孔复合体 → 细胞核
  - **线粒体定位途径**：细胞质 → TOM/TIM 转运体 → 线粒体
  - **过氧化物酶体定位途径**：细胞质 → PEX 转运体 → 过氧化物酶体
- 设计分层树的 9 个 sigmoid 决策节点对应的生物学分选决策：
  - 是否有 N 端信号肽？→ 是否进入内质网？
  - 是否含跨膜结构域？→ 是否为膜蛋白？
  - 是否含有核定位信号（NLS）？→ 是否进入细胞核？
  - 是否含有线粒体定位信号（MTS）？→ ...
- 将分层树逻辑翻译为前端可展示的决策流程图
- 准备答辩中用到的"蛋白质分选途径"生物学故事线

## 附录 A：技术决策速查

### ESM-2 模型选择

| 模型 | 参数量 | 嵌入维度 | 推理速度 | 推荐场景 |
|------|--------|---------|---------|---------|
| `esm2_t6_8M_UR50D` | 8M | 320 | 极快 | CPU 环境，快速原型 |
| `esm2_t12_35M_UR50D` | 35M | 480 | 快 | CPU 环境，平衡选择 |
| `esm2_t30_150M_UR50D` | 150M | 640 | 中等 | **推荐**：精度与速度平衡 |
| `esm2_t33_650M_UR50D` | 650M | 1280 | 慢 | GPU 环境，追求最高精度 |

**建议**：如有 GPU，选 `esm2_t30_150M_UR50D`（640 维）；如仅 CPU，选 `esm2_t12_35M_UR50D`（480 维）。

### 模型输入维度适配

PyTorch 模型的 `n_feat` 参数根据所选 ESM-2 模型调整：

| ESM-2 模型 | n_feat |
|-----------|--------|
| `esm2_t6_8M` | 320 |
| `esm2_t12_35M` | 480 |
| `esm2_t30_150M` | 640 |
| `esm2_t33_650M` | 1280 |
